## 🌟 Featured Projects

### 📦 Scanova — Packaged Product Compliance Scanner
> *An AI-assisted compliance auditing system developed for the Smart India Hackathon.*
* **What it does:** Extracts text and barcodes from packaging images using OCR and evaluates label information against legal compliance standards.
* **Architecture:** Python • FastAPI • React • TypeScript • Supabase • OCR Pipeline

### 🤖 YouTube Shorts AI Agent
> *An automated end-to-end engine for generating and publishing short-form video content.*
* **What it does:** Performs topic discovery, AI script generation, media discovery via stock APIs, automated voiceover synthesis, word-synced subtitles via Faster-Whisper, and direct upload via the YouTube Data API.
* **Architecture:** Python • Faster-Whisper • TTS Engine • YouTube Data API • Video Processing

### 🎓 CampusPro — Smart Classroom Management System
> *A full-featured academic management portal designed to digitize daily classroom operations.*
* **What it does:** Real-time face-recognition attendance tracking via browser webcam, notes/assignment distribution, online tests, and automated performance reporting.
* **Architecture:** JavaScript • face-api.js • Firebase Auth & Realtime Database • Bootstrap • HTML5/CSS3
